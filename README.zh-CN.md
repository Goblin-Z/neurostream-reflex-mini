# NeuroStream-Reflex Mini

English | [简体中文](README.zh-CN.md)

**0.77B 中文神经形态语言模型**——外部训练 + 内部意识流的双循环架构。记忆与思考在每一步计算中交融，形成持续向前的自指循环。

## 核心亮点

### 为什么是双循环？

模型不只是"回应输入"——**没人说话时它也在持续"思考"**。

- **外循环（交互层）**：把输入 + 记忆 + 状态转化为对话——模型的"行动"层，快速、响应、扎根于当前对话
- **内循环（意识层）**：后台持续运行——演化内部状态、强化专家（Hebbian）、巩固记忆、评估自身不确定度——"反思"层，缓慢、自指、不依赖外部刺激

两者构成**自指循环**：每一步计算改变状态，新状态决定下一步计算。模型"记得什么"影响它"想什么"，它"想什么"又成为新记忆。循环在两个尺度闭合：内部微循环（状态→思考→新状态）与跨交互宏循环（对话→学习→记忆→下一次对话）。

### 主动求证（知道自己不知道什么）

模型**困惑时会主动提问**：

- 专家携带内部不确定度信号（sigma）。当 sigma 超过阈值，模型"意识到自己不确定"——不是靠规则，而是靠自身内部状态
- 它从困惑状态生成澄清问题，向用户反问
- 你的回答成为学习信号（困惑专家获得聚焦强化）——模型更新，sigma 下降，停止提问（涌现冷却：学习本身即冷却，无定时器）
- 如果疑问未解决（sigma 持续高），它会再次追问——真正的求知循环，不是脚本

这是**元认知**的雏形：模型监测自身不确定度并据此行动，闭合"困惑→提问→学习→解决"的回路。

### 多层记忆

- **逐词记忆**：注意力直达历史 token 表示——模型能复述"实际说过的话"，而非摘要
- **对话主题**：内部状态编码对话在聊什么
- **长期知识**：可学习记忆库保存语义记忆
- **自发巩固**：记忆被模型**实际使用**得越多（由其自身注意力衡量）就越重要——成熟记忆自动蒸馏进权重，无需固定计划

### 部署即学习

模型**在部署过程中持续学习**——每一次对话都是训练步骤：

- **在线训练**：每次回复后，模型基于对话在线微调（记忆与状态全程参与）——聊得越多，越擅长这类对话
- **Hebbian 更新**：每个内部步实时强化专家
- **自发巩固**：高频使用的记忆自动蒸馏进权重
- **架构自修改**：专家分裂/裁剪/加层在运行时发生

它是一台**在使用中学习的系统**，不是冻结的产物。

### 其他亮点

- **Hebbian 学习**：专家通过局部关联强化（"一起放电的神经元连在一起"），非全局反向传播
- **架构自修改**：模型随学习自动分裂/裁剪/新增专家

## 架构

```
                        ┌──────────────────────────────────────────┐
                        │              记忆系统                      │
                        │  逐词(KV缓存)  主题(h_t)  知识(可学习槽)    │
                        └────▲────────────▲─────────────▲───────────┘
                             │            │             │
   外循环（交互层）           │   写入      │   读取      │
   ┌────────────┐  生成  ┌───┴──────┐    │             │
   │  用户输入    │───►───│  思考     │◄───┴─────────────┘
   └────────────┘        └───┬──────┘    (h_state + 记忆)
                             │ 新状态/新记忆
   内循环（意识层）           ▼
   ┌──────────────────────────────────────────────────────┐
   │  每步（持续运行，无需外部输入）：                       │
   │  A. 取状态 → 噪声 → 想象(SelfModel) → 前向思考        │
   │  B. Hebbian 更新（强化被使用的专家）                   │
   │  C. 世界模型学习 + Critic 价值                        │
   │  D. 状态写入记忆（KV/语义槽/辩证缓冲）                 │
   │  E/F. 巩固（记忆蒸馏进权重）                          │
   │  H. 主动求证（sigma 高 → 反问用户）                    │
   │  记忆参与每一步计算；每一步产生新记忆供下一步          │
   └──────────────────────────────────────────────────────┘
```

**循环闭合**：内循环持续演化状态与记忆；外循环读取该状态说话；说话又写回新记忆进入循环——同一个自指循环在两个尺度上运行。

| 组件 | 说明 |
|------|------|
| `core/` | 模型主干（MoE/Attention/SelfModel/MemoryBank） |
| `loop/` | 内部循环（意识流：Hebbian/巩固） |
| `learn/` | 在线学习（Hebbian 更新/Critic） |
| `interaction/` | 外部交互（对话/求证/反馈） |
| `config/` | 模型配置 |

## 模型规格

- **架构**：24 层 GQA + RoPE + SwiGLU MoE（4 稳定 + 2 可塑专家）+ 块间 Delta 注意力残差
- **词表**：Qwen2.5（151936）
- **参数量**：769M
- **训练**：15B tokens 中文预训练 + 教师（Qwen2.5-1.5B-Instruct）QA/多轮蒸馏
- **记忆**：128 个可学习记忆槽 + 4 轮 KV 对话缓存 + 注意力驱动的自发巩固

## 部署命令速查

| 命令 | 功能 |
|------|------|
| `stats` | 内循环状态（steps/loss_int/sigma/can_ask/异常） |
| `clear` | 清空会话记忆（L0 历史 + KV） |
| `quit` | 退出 |
| `--no-internal-loop` | 纯生成对照 |
| `--no-arch-self-mod` | 关闭架构自修改（默认开） |
| `--verify-threshold 0.45` | 调低主动求证门槛 |

## 已知限制

- 0.77B 容量：复杂推理/长文知识有限
- 模型回答能力受训练数据覆盖限制（未学过的指令会答非所问）
- 记忆的有效利用依赖记忆微调（`train_memory.py`）——结构就绪 + 训练强化
- 复杂角色设定指令效果差（建议短指令交互）
